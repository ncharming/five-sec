# Quickstart: 一次性待办与过期分类（specs/007）

真机手测场景（`gradle :app:installDebug` 或 Android Studio Run；配合系统日期调整或跨日等待）：

1. **一次性当天**：新建待办选「仅今天」→ 今日区可见可勾；触发拦截（打开抖音）→ 卡片出现该条、计入 D/T；勾选完成后拦截卡片 D/T 分子 +1。
2. **过期流转**：留一条「仅今天」未完成，把系统日期调到明天（或等跨日）回到待办页 → 该条进入「过期待办 (1)」区、无勾选框无开关、副行显示昨天日期；触发拦截 → 卡片不含该条。
3. **改为今天**：过期区 ⋯ → 改为今天 → 条目回今日区、可勾选、副行创建时间未变；再勾选完成。
4. **完成自动清理**：把已完成的一次性留到明天 → 两区都不出现（惰性清理）。
5. **规则转换**：把一条「每天」待办编辑为「仅今天」→ 当天轮到；再改回「每天」→ 恢复每日轮到；转换过程完成状态与创建时间不变。
6. **创建时间**：新建条目副行=今天；从 v6 覆盖升级进来的老条目副行=「—」；点条目看全文弹窗同步。
7. **覆盖层截断与对齐**：建一条 20+ 字的今日待办 → 拦截卡片只显示前 12 字 + …；「今日待办 D/T」标题与条目整体左对齐，提示语/倒计时/按钮仍居中。
8. **覆盖升级回归**：v6 装机（含待办若干）→ 覆盖安装 v7 → 条目/文本/规则/完成状态零丢失，老条目行为与升级前一致。

验收：`gradle :app:assembleDebug`、`gradle :app:testDebugUnitTest` 全绿。
