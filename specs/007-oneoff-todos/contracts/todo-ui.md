# Contract: 待办 UI 渲染规则（specs/007）

## 待办页（TodoScreen）两区

| 区 | 内容 | 排序 | 空态 |
|---|---|---|---|
| 今日待办 | 一切未过期条目（含：重复类不轮到灰显「今天不用做」、停用弱化、今日一次性已勾选划线） | id 升序（创建顺序，现状） | 两区皆空显示既有 todos_empty |
| 过期待办 (n) | 过期一次性条目 | 有效期日升序（最早失败在前），同日按 id | 整卡不显示 |

行结构：

- 今日区行（现状 + 副行日期）：勾选框（停用/不轮到禁勾）+ 标题（单行省略、完成划线、点行看全文）+ **副行日期** + 启用开关 + ⋯（修改/删除，文案缩短前为「重命名/删除待办」）。
  - 副行 = 创建日 yyyy-MM-dd；老条目「—」；启用且不轮到时追加「 · 今天不用做」。
- 过期区行：标题（单行省略、点行看全文）+ 副行=有效期日 + ⋯（改为今天/删除）。**无勾选框、无启用开关、无迟到补勾**。

规则编辑器：四选一 SegmentedButton（每天/每周几/每N天/单次，文案缩短、选中不显示 ✓；选每N天时下方实时展示「下次执行」日期）；单次（原「仅今天」）选中时显示提示文案「只在今天生效，未完成将进入过期待办」；其余分支沿用 006 交互。可双向转换。

详情弹窗：全文 + 副行日期（今日区=创建日、过期区=有效期日）。

上限：20 条两区共享（名额满提示沿用）。

## 拦截覆盖层卡片（BlockingOverlay）

| 项 | 规则 |
|---|---|
| 条目截断 | 前 **12** 字（超长加 …，省略号不计入 12）——specs/005 的 30 字口径收紧 |
| 条目排序 | 类型优先级 仅今天→每N天→每周几→每天（`TodoRecurrence.overlayPriority`），同类型内创建日倒序、同日以 id 倒序补足（`TodoRepository.overlayOrder` 纯函数，快照侧预排，视图层零排序逻辑） |
| 对齐 | 卡片内「今日待办 D/T」标题与条目整体**左对齐**；卡片外提示语/倒计时/按钮维持居中 |
| 快照过滤 | 只含「启用且轮到」：一次性当天计入分母，过期/非当天天然排除（isDue 口径，服务零改动） |
| 其余 | 展示排序后前 **3** 条（用户拍板：一次性/间隔类优先露出）、超出折叠、全部完成态、空清单整块隐藏——specs/005 契约不动 |

- `todos_section_today` 今日待办
- `todos_section_expired` 过期待办（%1$d）
- `todos_date_unknown` —
- `todos_menu_revive` 改为今天
