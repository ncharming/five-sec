# Spec: 周/月复盘卡（specs/014）

## 背景

统计页的数字全是**绝对值**（本周拦截 12 次、抵制率 50%），回答不了自律工具留存最关键的问题：
「我最近变好了吗」。specs/011 的抵制率证明了对比型指标的表达力；本 spec 把「对比」结构化——
统计主页新增一张**本期 vs 上期**复盘卡，把记录升级为反馈闭环。纯本地聚合既有三表，零新表零网络。

## 需求

1. 统计主页（双 Hero 卡之下）新增「复盘」卡：**本期 vs 上期**对比，档位二选一：周（本周 vs 上周，
   默认）/ 月（本月 vs 上月），卡头小分段切换。
2. 对比指标四行，各自带变化方向符号（↑ 绿 = 变好、↓ 红 = 变差、— 灰 = 持平/无可比数据）：
   - **拦截次数**（本期总数 vs 上期总数；上期减少 = ↑ 好转——被拦得越少说明入口冲动越少）；
   - **抵制率**（取消/(取消+打开)，INTERRUPTED 不进分母；上升 = ↑；任一期分母 0 显示 — ）；
   - **待办完成次数**（todo_completions 计数；上升 = ↑）；
   - **平均单场停留**（usage_sessions 按期 SUM(durationMillis)/COUNT；下降 = ↑ 好转）。
3. 「变好」的方向语义按指标定义（拦截↓好、抵制率↑好、完成↑好、停留↓好），符号颜色跟语义不跟数值方向。
4. 上期无任何数据时对应行显示 — （不伪造基线）；本期 0 上期 0 也显示 — 。

## 方案

- **零新表**：全部走既有 DAO 区间查询（拦截按应用聚合后求和、抵制率用取消/打开计数、完成计数、
  会话时长/场次），在 `StatsViewModel` 组装；对比两期窗口由档位推导（周/月自然周期，复用
  `DateUtil.startOfWeekMillis`/`startOfMonthMillis`）。
- **纯逻辑下沉**：方向判定与文案格式化收进 `util/ReviewTrend`（输入两期值 + 方向语义枚举，
  输出 Better/Worse/Flat/NoBaseline），单测覆盖（含 0/0、分母 0、持平）。
- **UI**：`StatsMainPage` 底部新卡（白卡 + 卡头档位分段 + 四行指标），组件进 `StatsMainPage.kt`；
  主页已有 `todayKey` 滚动 → 复盘卡随零点换期（本周/本月窗口重算）。
- **抵冲口径注意**：抵制率对比只在两期分母均 >0 时给出方向，否则 — 。

## 验收

- 造数：本周拦截 5（取消 3/打开 2）、上周拦截 8（取消 2/打开 6）；完成本周 6 次/上周 3 次；
  会话本周 2 场共 20 分钟、上周 2 场共 50 分钟 → 复盘卡显示：拦截 5 ↓（绿）、抵制率 60% ↑（绿）、
  完成 6 ↑（绿）、平均停留 10 分钟 ↓（绿）；
- 上期无数据：四行全部 — ；档位切「月」窗口随之一换；
- 跨零点（周一 00:00 / 月 1 号）后卡内「本期/上期」自动换窗。

## 红线沿用

不新增表与预聚合；统计=事件流水实时聚合；纯离线；今日四卡锚点不触碰（复盘卡在其下方新增）。
