# Quickstart: 回弹层停留预算（specs/015）

真机手测（`adb install -r` 覆盖安装；前置：会话心跳修复已在包内，今日累计才可信）：

1. **设置预算**：设置 Tab → 使用时长守护卡 → 「每日停留预算」→ 选 60 分钟（默认「不设」）。
2. **未触线展示**：刷目标应用到回弹（如 15 分钟档）→ 回弹层副行显示「今日已停留 15 分钟（预算 60）」。
3. **触线警示**：继续刷两场后再到回弹，累计 ≥60 分钟 → 副行照常 + 标题上方红字「已达今日预算 60 分钟」（恰好）或「已超出预算 N 分钟」（超出），弹出短震两次（间隔可感知）。
4. **多场累计**：预算 = 今日该应用已结束会话之和 + 本场进行中的墙钟时长；回弹选「结束」后下一场照常累计。
5. **关闭**：预算切「不设」→ 下一场回弹层回到原副行（「休息一下…」），无警示无二次震动。
6. **FR-014**：触线后「继续 N 分钟」仍可点，预算不拦人。
