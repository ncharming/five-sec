# Quickstart: 每日待办与拦截流程打通

**Date**: 2026-09-23 | **Spec**: [spec.md](spec.md)

端到端验证指南。自动化验证（CI / 本地）：

```bash
./gradlew :app:testDebugUnitTest        # 全部单测（含 TodoRepository/HintRepository/迁移/TodoViewModel）
./gradlew :app:assembleDebug            # 编译
```

## 前置

1. 真机/模拟器安装 debug 包（`./gradlew :app:installDebug`；升级场景先装旧版本造数据）。
2. 无障碍服务已开启；清单中已有目标应用（默认抖音/小红书/B站）。

## 场景验证

### 场景 A：待办页管理闭环（US1 / SC-004）

1. 冷启动 → 默认落「待办」Tab，空态文案引导，无预置数据。
2. 点"+"输入"背 20 个单词"确认 → 列表出现该条；输入 40 字 → 截断在第 30 字；只输空格 → 确认不可用。
3. 点复选框勾选 → 划线完成态；再点恢复。
4. ⋯菜单 → 重命名（改文案生效）、删除（确认后消失）、停用（条目弱化且不可勾选）。
5. 建满 20 条 → 名额行 20/20 → 点"+"弹名额已满提示。

### 场景 B：拦截页卡片与勾选联动（US2 / SC-001）

1. 建待办 A、B（均未完成）→ 打开目标应用触发拦截 → 卡片「今日待办 0/2」+ `○ A`、`○ B`。
2. 解锁取消回桌面 → 进待办页勾掉 A → 再次触发拦截 → 「今日待办 1/2」+ 仅 `○ B`。
3. 建到 5 条未完成 → 拦截页显示前 3 条 +「…还有 2 条」。
4. 全部勾掉 → 拦截页仅「今日待办已全部完成 ✓」；全部停用 → 拦截页无待办区块。
5. 覆盖层打开期间无任何可点待办交互（只读）。

### 场景 C：每日重置（US1/US2 / SC-002）

1. 今日勾掉全部待办，确认拦截页显示"已全部完成 ✓"。
2. 系统日期改为次日（或等到次日）→ 打开待办页：全部回到未完成；拦截页计数归 0/n。

### 场景 D：信息架构与零回归（US3 / SC-006 / FR-013）

1. 底部 Tab 顺序 [待办, 拦截, 提示语, 统计]；冷启动默认「待办」。
2. 「拦截」页：页头"拦截/给无意识的刷手机加一道减速带"；总开关卡在上（含无障碍状态行，一键开启/跳设置行为与原五秒页一致）；名额行、应用卡片、名额满提示在下。
3. 总开关关闭 → 拦截不再触发；应用增删/启停、统计页四卡与各档位数字与重构前一致。

### 场景 E：提示语循环与游标持久化（US4 / SC-005）

1. 清空自定义池，连续拦截 8 次 → 内置 7 条按资源顺序轮转，第 8 次回到第 1 条。
2. 池中添加"早点睡觉" → 内置轮完接"早点睡觉"再回内置第 1 条。
3. 轮到第 3 条时 `adb shell am force-stop com.fivesec.app` 杀进程 → 再次拦截从第 4 条续接。
4. 覆盖层上不存在提示语输入框/保存按钮（功能已移除）。
5. 旧版本（v4）保存过"留一句话" → `adb install -r` 覆盖升级 → 该文本出现在「提示语」页池中并可被轮到（stack→pool 迁移）。

### 场景 F：升级与数据留存（FR-012/FR-013）

1. 旧版本造好拦截记录与统计 → 覆盖升级 → 统计页数字不变（interception_events 零触碰）。
2. 拦截触发、5 秒锁定、打开/取消行为与升级前一致。
3. `./gradlew :app:testDebugUnitTest` 全绿（含 v4→v5 迁移用例）。

## 通过标准

- A~F 全部场景观察结果与预期一致；
- 单测/编译全绿（CI 触发于 push master 或手动 Run workflow）。

## Notes

- 场景 B/E 的卡片文案与折叠行为以 [contracts/todo-ui.md](contracts/todo-ui.md) 渲染规则表为准。
- 自动化锚点：`TodoRepositoryTest`（快照过滤/日期映射/上限/校验）、`TodoViewModelTest`（今日口径转发）、`HintRepositoryTest`（循环/续接/取模）、`AppDatabaseMigrationTest`（v4→v5：todos 可用 + stack 改挂 pool）。
