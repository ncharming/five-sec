# Quickstart: 添加应用搜索 + 应用级今日统计（品牌色展示）

**Spec**: [spec.md](spec.md) · **Plan**: [plan.md](plan.md) · **Contracts**: [add-app-search](contracts/add-app-search.md) · [perapp-stats-card](contracts/perapp-stats-card.md)

端到端验证指南。列出可运行的验证场景、前置条件、运行命令与期望结果。**不含实现代码**（实现细节属 `tasks.md` 与实现阶段）。

## 前置条件

- 已按 001 构建并可运行的 `五秒 / five-sec` 应用（拦截机制、应用清单、统计页已可用）。
- 一台真机或模拟器（建议安装 ≥ 30 个第三方应用以验证搜索过滤；为压测可装 200+ 应用）。
- 已完成首次权限引导（`onboarding_completed = true`），目标清单含至少 1 个应用（默认抖音/小红书/B站）。
- 本特性新增依赖 `androidx.palette:palette-ktx` 已加入 `app/build.gradle.kts`。

## 构建 & 运行

```bash
# 构建 APK
./gradlew :app:assembleDebug

# 安装到已连接设备/模拟器
./gradlew :app:installDebug
```

> Windows Git Bash 下用 `./gradlew`；PowerShell 用 `.\gradlew.bat`。

## 测试命令

```bash
# 单元测试（搜索过滤纯函数、应用级今日统计 Flow 聚合）
./gradlew :app:testDebugUnitTest

# 仪器化/UI 测试（搜索框交互、空状态、统计卡片渲染与品牌色着色）
./gradlew :app:connectedDebugAndroidTest
```

## 验证场景 1 — 添加应用搜索

**目标**：覆盖 [add-app-search 契约](contracts/add-app-search.md)，对应 User Story 1。

1. 进入 设置 → 应用清单，点 `+` 打开添加选择器。
2. **期望**：选择器顶部出现搜索框，下方列出全部可添加应用，已添加应用置灰。
3. 在搜索框输入某个应用名片段（如"小红"）。
4. **期望**：列表实时过滤为名称或包名含该片段的应用（< 0.5s）；输入"com.xingin"应能命中包名匹配。
4. 清空搜索框 → **期望**：列表恢复全部可添加应用。
5. 输入一个不存在的关键词（如"zzzqqq"）→ **期望**：显示"未找到匹配的应用"空状态。
6. 搜索并点选一个未添加应用 → **期望**：应用加入清单，选择器关闭，清单刷新。
7. 目标清单已达 3 个时再点 `+` → **期望**：显示"最多可添加3个应用…"提示（001 既有）。

**压测（SC-001）**：在安装 200+ 应用的设备上重复步骤 3，确认过滤无明显卡顿（p90 < 0.5s）。

## 验证场景 2 — 应用级今日统计（品牌色）

**目标**：覆盖 [perapp-stats-card 契约](contracts/perapp-stats-card.md)，对应 User Story 2。

1. 触发若干拦截并做出不同选择，制造可识别数据，例如：
   - 小红书：今日触发 3 次拦截，其中 2 次选"打开"、1 次选"取消"。
   - 抖音：今日触发 1 次拦截，0 次打开（取消）。
2. 进入 设置 → 统计页。
3. **期望**：除既有总体统计外，出现每个目标应用的今日统计卡片：
   - 小红书卡片：今日拦截 **3**、今日打开 **2**。
   - 抖音卡片：今日拦截 **1**、今日打开 **0**。
4. **期望**：每张卡片使用各自应用的品牌色作为主题色，两张卡片颜色明显不同；卡片上文字清晰可读（对比度达标）。
5. 查看一个今日无拦截的目标应用 → **期望**：其卡片仍显示"今日拦截 0 / 今日打开 0"。
6. （跨天）次日再次进入统计页 → **期望**："今日"指标仅反映新一天数据，不含昨日。

**口径核对**：可在 `interception_events` 表（设备端 Room）按 `packageName + timestamp >= startOfDay` 手工核验 `todayInterceptions`，按 `outcome='OPENED'` 核验 `todayOpened`，与卡片数值一致（SC-004）。

## 验证场景 3 — 品牌色兜底（可选）

1. 构造一个图标为纯白/纯黑或无法提取代表色的应用（或断网/极简图标模拟），加入目标清单。
2. 进入统计页 → **期望**：其卡片回退到品牌健康绿主题色且文字可读，应用不崩溃（US2-6 / FR-012）。

## 期望的最终状态

- 添加任意应用都能通过搜索在秒级内定位（SC-002/003）。
- 统计页为每个目标应用展示品牌色今日卡片，数值与事件表一致、跨天自动归新（SC-004/005/006）。
- 全程离线、无网络、无账号；既有 001 功能与总体统计不受影响。
