# Quickstart: 单次待办默认提醒手测（specs/013）

真机 `adb install -r app/build/outputs/apk/debug/app-debug.apk` 后按序验证（覆盖安装可同时验证
存量提醒时刻零迁移：旧单值提醒照常响）。

## 1. 默认三时刻

1. 待办页 → ＋ 新建 → 规则段切到「单次」→ 提醒区自动出现 `20:00`、`21:00`、`22:00` 三枚 chips
   与「单次待办默认当天 20:00、21:00、22:00 各提醒一次，可增删改」提示。
2. 保存 → 列表行副行显示「提醒 20:00、21:00、22:00」；⋯ 菜单「修改」重开弹窗，三时刻仍在。

## 2. 预填的让位与保留

1. 新建弹窗：切「单次」（预填出现）→ 切回「每天」→ 预填消失（默认值不泄给重复类）。
2. 切「单次」→ 移除一枚（如 22:00）→ 切「每天」→ 时刻保留（用户动手过不被吞）。
3. 切「单次」→ 移除全部三枚 → 保存 → 该单次待办无提醒（默认可关）。
4. 满三枚时「添加时刻」置灰，下方提示「最多 3 个提醒时刻」。

## 3. 双通道触发 + 完成即取消

> 建议把其中一枚时刻改到「两分钟后」做快速验证（点 chip 编辑）。

1. 到点前确保：无障碍服务开启（亮屏补拉依赖）、通知权限已授（13+）、屏幕可亮。
2. 到点 → **同时**出现：类闹钟全屏提醒页（完整内容 + 每条「完成」）与系统通知（高分横幅/常驻）；
   铃声 + 震动即时响（息屏/亮屏都响）。
3. 在提醒页（或待办页）勾掉该待办 → 等到下一枚时刻（如 21:00）→ **不再**弹页、不再通知、不再响铃。
4. 未完成对照：另建一条不勾 → 三枚时刻各自到点各响一次（同分钟多条聚合为一页）。

## 4. 存量回归（010 行为不回退）

1. 覆盖安装后，升级前设的旧单值提醒（如每天 18:30）照常在轮到日触发、行内角标正常显示。
2. 旧单次待办（无提醒）编辑切规则来回切换，不产生意外时刻。
