# Quickstart: 待办习惯模板（specs/019）

真机手测（`adb install -r` 覆盖安装）：

1. **新建见模板**：待办页 + → 弹窗输入框上方 5 个模板 chips（喝水 8 杯/拉伸 5 分钟/读书 20 页/走动 10 分钟/复盘今天的 3 件事）。
2. **一键填入**：点「读书 20 页」→ 输入框整体替换为该文本、字数计数联动（3/200）；再点「喝水 8 杯」→ 再次整体替换。
3. **编辑不显示**：既有待办 ⋯ → 修改 → 无模板区。
4. **默认不动**：不点模板直接手输/保存/取消，规则默认（每天）与提醒默认（无）与现状一致。
