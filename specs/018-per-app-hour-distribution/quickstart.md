# Quickstart: 单应用时段分布（specs/018）

真机手测（`adb install -r` 覆盖安装）：

1. **造数**：只给抖音造几条 23 点附近的拦截；B 站零或别的小时。
2. **下钻**：统计 → 应用拦截统计 → 点抖音应用卡 → 卡下展开抖音自己的 24 桶（23 号桶有柱、峰值高亮）；再点一次收起。
3. **互斥**：展开抖音后点 B 站卡 → 抖音收起、B 站展开（无数据=全零图 + 基线 +「共 0 次」）。
4. **周期联动**：保持 B 站展开，切周期 → 数据随区间重算、展开态保持。
5. **全局卡不受影响**：页顶全局时段分布照常。
