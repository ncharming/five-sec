# Quickstart: 本地数据导出 CSV（specs/017）

真机手测（`adb install -r` 覆盖安装）：

1. **导出**：设置 Tab 底部「导出数据」→ 系统文件选择器（建议名 `five-sec-export-日期.csv`）→ 选位置保存 → snackbar「已导出」。
2. **内容**：用文本编辑器/Excel（双击直接开，中文不乱码——UTF-8 BOM）核对四段：`# 拦截事件`（时间双列：epoch+本地时间、应用、结局、完成锻炼）、`# 使用会话`、`# 待办完成`（过期补完列）、`# 待办清单（当前快照）`。
3. **转义**：建一条含逗号/引号/换行的待办再导出 → 该字段被双引号包裹、内部引号翻倍。
4. **取消静默**：文件选择器按返回取消 → 无 toast 无副作用。
5. **只读**：导出前后统计页各数字零变化。
