# Quickstart: 任务完成统计

**Feature Branch**: `008-todo-stats`

## 构建

```bash
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
```

## 真机手测场景

### 场景 1：升级迁移零丢失（覆盖安装）

1. 在旧版本（v7）下添加若干待办（每天/周几/间隔/仅今天各一），完成几条勾选，制造若干拦截事件。
2. `adb install -r app/build/outputs/apk/debug/app-debug.apk` 覆盖安装新版。
3. 打开 App：待办页两区条目原样；统计页正常进入。

### 场景 2：今日任务三数口径

1. 待办页造数：每天 A（未勾）、每天 B（已勾）、仅今天 C（未勾）、仅今天 D（昨天改成过期，或改系统日期制造）、停用每天 E、间隔 3 天 F（今天完成）。
2. 统计页今日任务卡期望：任务 = A+B+C（F 完成当天进入灰显期不计入，D 过期不计入，E 停用不计入）；完成 = B；过期 = D。
3. 对照拦截覆盖层 D/T：分母应等于 任务 x（触发一次拦截看卡片 D/T）。

### 场景 3：勾-取消-再勾不重复

1. 勾选 A → 统计页任务历史（日/今天）显示 A 完成 1 次，总完成 1。
2. 取消勾选 → 显示总完成 0、空态文案。
3. 再勾选 → 恢复 A 完成 1 次（不是 2）。

### 场景 4：历史聚合与共享周期

1. 周一勾 A、周二勾 A+B、周三勾 B（不同天各一次勾选）。
2. 统计页 → 任务完成统计 → 档位「周」：总完成 4；条目卡 A 完成 2 次、B 完成 2 次（同次数按文本排序）。
3. 切到「应用拦截统计」：档位仍是「周」、周期仍「本周」（共享选择）；再切回任务页同样保持。
4. 档位「月」→ 本月：总完成 ≥4；Chip 列表从本月到 1 月。

### 场景 5：删除条目历史不失联

1. 删除条目 A（待办页 ⋯ → 删除）。
2. 任务完成统计（本周）：A 的完成次数卡仍显示，文本为删除前的快照。

### 场景 6：二级页返回

1. 主页点「应用拦截统计 ›」进入 → 系统返回手势 → 回统计主页（不是退出 App）。
2. 任务完成统计同理；切到「待办」Tab 再切回「统计」：仍在刚才的二级页（现场保留）。

### 场景 7：锚点回归

1. 今日拦截三列卡数值与旧版口径一致（当天拦截几次/取消几次/打开几次）。
2. 连击卡数值不变；四 Tab（待办/提示语/统计/设置）正常。
