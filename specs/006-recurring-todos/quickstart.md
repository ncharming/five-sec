# Quickstart: 重复待办（specs/006）端到端手测

前置：真机或模拟器；`gradle :app:assembleDebug` 产出 debug APK；覆盖安装用 `adb install -r`（**必须保留旧数据**，用于场景 A 的迁移验证）。符号说明：✓ = 预期成立，✗ = 任一不成立即缺陷。

## 场景 A：老数据升级零感知（US3 / FR-010 / SC-004）

1. 用**升级前版本**建 3 条待办：A1 启用并勾选、A2 启用未勾、A3 停用。
2. `adb install -r` 覆盖安装新版本 → 打开待办页。
3. ✓ A1/A2/A3 全部还在，文本/启用开关/勾选状态与升级前一致。
4. ✓ 编辑任一条查看规则区：均为「每天」。
5. ✓ 次日（或调整系统日期）打开：A1 回到未完成（每日重置不变）。
6. ✓ 拦截页/统计页行为无任何变化（回归锚点）。

## 场景 B：按星期几重复（US1 / FR-002/005/006/007 / SC-001）

1. 新建「周三锻炼」，规则选「按星期几」，只勾周三 → 保存。
2. 在周三（或调系统日期）查看：✓ 正常展示、可勾选、点行可看全文。
3. 触发拦截（打开目标应用）：✓ 卡片出现该条目（未完成时）且计入「今日待办 D/T」分母。
4. 切到周四：✓ 条目灰显 +「今天不用做」+ Checkbox 不可勾；✓ 条目未消失，改名/删除/停用入口可用，点行仍可看全文。
5. 周四触发拦截：✓ 卡片不出现该条目。
6. 回编辑弹窗，取消全部周几：✓ 保存按钮禁用且提示「至少选择一天」。

## 场景 C：每 N 天滚动（US2 / FR-003 / SC-002）

1. 新建「换床单」，规则「每 N 天」N=3 → 保存。
2. 当天：✓ 立即轮到可勾（从未完成恒到期）。
3. 勾选完成 → 当天：✓ 显示已完成（当日完成态正常）；拦截卡片该条从 ○ 列表消失、分母仍含它。
4. 明天、后天：✓ 灰显「今天不用做」不可勾；✓ 拦截卡片不出现该条、分母不含它。
5. 第 3 天：✓ 重新轮到且为未完成（复活）。
6. 到期后连续拖 5 天不做：✓ 每天都保持轮到可勾（持续提醒，不消失不归位）。

## 场景 D：混合清单计数（FR-006/007 / SC-003）

1. 保留「周三锻炼」（周四不轮到）与「换床单」，另建 3 条「每天」待办。
2. 在周四查看拦截卡片：✓ 分母只含轮到的条目（每天 3 条 + 换床单如已到期则计入，周三锻炼不计）。
3. 把全部轮到条目删光/停用，只剩不轮到的：✓ 卡片整块隐藏。

## 场景 E：规则编辑即时生效（US4 / FR-008/009）

1. 「每天」待办今天勾选完成 → 编辑改为「每 3 天」→ 保存。
2. ✓ 完成状态保持（已划线）；✓ 明天起灰显 2 天、第 3 天复活（锚点=今天，未重置）。
3. 「每 3 天」待办（已完成、灰显中）编辑改回「每天」→ ✓ 明天轮到；今天完成态不受影响。

## 场景 F：校验与边界（FR-002/003 / SC-005）

1. 周几规则全空保存 → ✓ 被拒（场景 B.6 已验，此处验编辑路径同样被拒）。
2. 每 N 天输入 1 → ✓ 收敛为 2；输入 999 → ✓ 收敛为 365。
3. 每 N 天输入 2 → ✓ 完成次日即复活；N=365 → ✓ 完成后整年不再出现。

## 场景 G：回归扫描（FR-011/012）

1. ✓ 拦截/取消/打开与统计四卡数值如常（待办与规则零影响）。
2. ✓ 提示语循环如常（30 字口径不变）。
3. ✓ 全程无网络、无通知、无新增权限申请。
