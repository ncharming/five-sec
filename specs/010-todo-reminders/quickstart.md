# Quickstart: 待办到点主动提醒手测（specs/010）

真机 `adb install -r app/build/outputs/apk/debug/app-debug.apk` 覆盖升级后逐项过：

## 0. 升级零感知（回归锚点）

1. 老版本装好若干待办（含重复类与单次）→ 安装 010 构建。
2. 打开待办页：列表/勾选/规则/两区/详情逐位不变；无任何提醒角标；无横幅。
3. 触发一次拦截：覆盖层今日待办卡片与升级前一致（零改动锚点）。

## 1. 设置与编辑提醒时刻

1. 新建「每天」待办，提醒区点「未设置」→ TimePicker 选 18:30 → 保存。
   ✓ 行内副行出现「提醒 18:30」；（Android 13+）首次保存弹通知权限请求。
2. 编辑该条改 07:00 → ✓ 角标变「提醒 07:00」。
3. 编辑点「清除」→ 保存 → ✓ 角标消失（该条不再排程）。
4. 「单次」待办设提醒 → ✓ 提示「只在有效期日当天响」。

## 2. 到点主动提醒（核心场景）

1. 每天待办 + 提醒设 2 分钟后（如现在 15:08 → 设 15:10），退到桌面。
2. 15:10：✓ **先响铃+震动**（响铃前台服务，不依赖任何点击/页面拉起）；**未打开五秒、未触发拦截**。
3. **亮屏路径**：✓ 提醒页直接弹出（无障碍服务运行时进程拥有后台启动豁免）；条目显示**完整内容**（多行原文），点条目旁「完成」→ ✓ 该条消失、铃停；回待办页确认已勾（完成事件进统计口径）。
4. **息屏路径**：按电源键息屏等待到点 → ✓ 自动亮屏、锁屏之上弹提醒页、响铃震动；锁屏上直接点「完成」可勾掉（无解锁要求）。
5. 重复步骤，这次不操作 → ✓ 60 秒后停铃、（若页面曾弹出）页面关闭、通知栏留静默通知；点开回到提醒页仍可完成。

## 3. 聚合与静默口径

1. 三条「每天」待办都设同一分钟 → 到点：✓ 只响一次、一页三条。
2. 「每周一/五」待办设 18:30，今天非周一/五 → 到点：✓ 静默不响。
3. 今天轮到的待办，到点前先勾完成 → 到点：✓ 静默；再取消完成（时刻已过）→ ✓ 不补响。
4. 停用某条（开关关）→ 到点：✓ 不响；重新启用 → 下个轮到日照常。
5. 单次待办跨日未完成（进过期区）→ ✓ 到点不响；「改为今天」后当天到点恢复提醒。

## 4. 恢复与降级

1. 设好提醒 → 重启设备 → 到点：✓ 仍响（开机重排）。
2. **息屏核心验证（修复轮三）**：待办页确认无「电池优化」横幅（有则点「去开启」→ 系统一键弹窗选允许）→ 设 2 分钟后提醒 → 按电源键息屏静置等待 → ✓ 到点自动亮屏、锁屏之上弹提醒页、准点响铃震动；状态栏在到点前有系统「即将闹钟」图标（setAlarmClock）。若部分 ROM 弹窗后仍不响，需再进「设置 → 电池 → 五秒」选「允许后台运行/无限制」（OEM 冻结策略，横幅文案已引导）。
3. Android 13+ 拒绝通知权限 → 横幅提示；到点**仍响铃震动**、页面补拉仍可工作（响铃已不依赖通知可见性；横幅只是可见性教育）；补开 → 横幅消失。
4. Android 14+ 关「全屏显示」→ 息屏时不再弹全屏页（高分横幅 + 响铃震动仍在；亮屏补拉页面不依赖此权限）；放行 → 恢复息屏全屏页。
5. 强停五秒（系统设置 → 强行停止）→ 到点：✗ 不响（系统机制，README 已记载）；重新打开 App 后下一场恢复。
6. 无障碍服务**未运行**时到点：✓ 仍响铃震动 + 息屏 FSI/亮屏横幅；部分 ROM 亮屏可能不直接弹页（点横幅进页）——无障碍运行（本应用常态）则直接弹页。

## 5. 勿扰

开启系统勿扰 → 到点：✓ 按系统默认（大概率静默/仅亮屏）；在系统勿扰设置把五秒加入「闹钟可中断勿扰」例外后 → 到点恢复响铃（App 侧无任何变化）。

## 自检口径（验证标准）

- `gradle :app:assembleDebug`、`gradle :app:testDebugUnitTest` 全绿（含 PlannerTest / 迁移 v9→v10 / 仓库提醒口径）。
- `interception_events` 无 DELETE、无破坏性迁移；覆盖层与统计页零改动。
- README「待办」段与「平台限制」段已同步；tasks.md 全勾。
